Built for smarter hostel operations

HostelPro is a production-style engineering college project that demonstrates authentication, REST APIs, MongoDB collections, admin workflows, and clean vanilla JavaScript UI patterns.

For students

Apply for rooms, track allotment, raise complaints, check fees, and keep profile information updated.

For admins

Manage rooms, students, payments, complaints, and hostel analytics from one dashboard.

For portfolios

The codebase uses MVC structure, Mongoose schemas, middleware, reusable frontend helpers, and beginner-friendly comments.
